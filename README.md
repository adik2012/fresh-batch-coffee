# Свежая Партия (Fresh Batch) — Коммерческий лендинг спешелти-кофейни и обжарочной

Адаптивный одностраничный лендинг кофейни-обжарочной: каталог кофе, дрип-пакетов и десертов, подбор вкуса онлайн-бариста и оформление заказа с доставкой или самовывозом.

## Демо

**[Открыть сайт на GitHub Pages](https://adik2012.github.io/fresh-batch-coffee/)**

На GitHub Pages автоматически активен интерактивный демо-режим портфолио: симуляция оплаты по QR-коду СБП и формирование чека в мессенджеры без списания средств. Серверный обработчик `send.php` предназначен для PHP-хостинга.

## Решаемые задачи бизнеса

- **Рост среднего чека.** Умная корзина показывает прогресс-бар до бесплатной доставки от 2 000 ₽ и предлагает добавить десерт или дрип-сет в один клик.
- **Снятие нагрузки с бариста.** Покупатель выбирает помол прямо в карточке товара, а двухшаговый квиз «Онлайн-бариста» подбирает кофе по вкусовому профилю и способу приготовления. Добавление рекомендации автоматически применяет промокод `DRIPO15` со скидкой 15%.
- **Удобство заказа.** Доступны доставка за 2 часа с проверкой адреса и самовывоз из кофейни со скидкой 10%. После оформления можно симулировать оплату по СБП и передать готовый чек в Telegram или WhatsApp.

## Возможности

- Каталог кофе, дрип-пакетов и десертов с выбором помола.
- Корзина с изменением количества, быстрыми допродажами и расчётом суммы.
- Единая скидка 15% по промокоду `DRIPO15` и отдельная скидка самовывоза.
- Бесплатный пробник доступен только вместе с платным товаром; количество пробников ограничено одной штукой.
- Поле адреса становится обязательным для доставки и отключается при выборе самовывоза.
- Обязательное согласие на обработку персональных данных.
- Демо-чек с адресом получения и ссылками для передачи заказа в мессенджеры.
- Адаптивная вёрстка для мобильных устройств, планшетов и широких экранов.

## Технический стек и архитектура безопасности

### Frontend

- Семантический HTML5, Tailwind CSS через Play CDN и Vanilla JavaScript (ES6+); без сборщика.
- Lucide Icons через CDN с проверкой целостности ресурса (SRI).
- Адаптивный Mobile-First интерфейс; проверенные ширины: 375, 768 и 1440 px.
- Динамические данные корзины, квиза и чека выводятся через `textContent`, без вставки пользовательского ввода как HTML.
- На GitHub Pages и при открытии статической версии форма работает в демонстрационном режиме.

### Backend (`send.php`, PHP 8.3)

- Серверный каталог является источником цен и допустимых товаров; сумма пересчитывается на сервере, а не принимается из браузера.
- Проверяются состав заказа, адрес доставки, промокод и согласие на обработку данных; заказ на 0 ₽ и более одного бесплатного пробника отклоняется.
- Повторяющиеся позиции с одинаковыми `id` и `grind` объединяются.
- Honeypot и файловый rate limit с блокировкой `flock` ограничивают автоматический спам и частые запросы.
- Входные данные нормализуются, а динамические значения экранируются при формировании HTML-сообщения для Telegram Bot API.
- `.htaccess` закрывает служебные файлы и скрытые каталоги; `.gitignore` исключает локальный `config.php` и `.env` из Git.
- Секреты бота задаются локально в `config.php`, который не следует коммитить. Пример настроек хранится в `config.example.php`.

## Production Roadmap

Чек-лист перед запуском реального приёма заказов:

1. Скопировать `config.example.php` в `config.php` (лучше разместить конфигурацию выше `document root` хостинга) и указать боевые `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Не добавлять `config.php` в Git.
2. Собрать стили через Tailwind CLI в минифицированный CSS-файл вместо Play CDN.
3. Подключить Cloudflare Turnstile или Yandex SmartCaptcha и резервную запись заказов в SQLite или JSONL.
4. Заменить демонстрационные контакты и реквизиты на реальные юридические данные ИП/ООО, настроить документы и процессы обработки персональных данных в соответствии с 152-ФЗ.

## Локальный запуск

Для просмотра интерфейса откройте `index.html` в браузере. Для проверки PHP используйте PHP 8.3; `send.php` принимает POST-запросы с JSON и требует файл `config.php` с настройками Telegram-бота. В статической версии на `file://` и GitHub Pages обработчик не вызывается — включается демо-режим.
